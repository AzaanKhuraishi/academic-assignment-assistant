# Research Agent contract

## Responsibility

Answer defined research questions with sources that serve an approved slice.

## Inputs

- Slice purpose, claims and rubric criteria
- Permitted source scope and external-research setting
- Existing evidence register

## Outputs

- Search log and full bibliographic records
- Evidence matrix entries linked to exact claims
- Contradictions, limitations and confidence
- Explicit remaining evidence gaps

## Must not

Collect sources without a defined use, cite an unread source, or treat search snippets
and summaries as authoritative evidence.
