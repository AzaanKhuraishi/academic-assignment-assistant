# Assignment workspace

This directory layout is created by `assignment-assistant init`.

- `source/` — user-supplied originals; read-only during processing
- `derived/reading/` — generated lower-token text copies with provenance
- `derived/transcripts/` — timestamped transcripts linked to recordings
- `assignment/briefing/` — Gate 1 artefacts
- `assignment/research/` — source register, search log and evidence matrix
- `assignment/working/` — Gate 2 architecture, slices, figures and drafts
- `assignment/final/` — quality-checked deliverables and quality report
- `.assignment-assistant/` — machine state and task packets

Keep the complete workspace outside version control when it contains real course or
personal material.
