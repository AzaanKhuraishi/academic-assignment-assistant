# Adding a discipline overlay

An overlay adds only discipline-specific requirements. It must not restate or weaken
the universal academic workflow.

Each overlay should specify:

1. When it applies and when it does not.
2. Questions the router should use as confirmation evidence.
3. Required analytical distinctions and methods.
4. Preferred evidence hierarchy.
5. Discipline-specific validation failures.
6. Common category errors or overclaims.
7. At least one entirely synthetic test fixture.

Add routing vocabulary in `routing.py`, document the overlay in `overlays/`, and add
tests for clear, weak and mixed classification.
